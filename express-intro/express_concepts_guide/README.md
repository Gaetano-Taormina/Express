**English:**
Understanding a concept with AI: mini guide. Study with AI.
Choose a previously covered concept and use AI as a tutor to explain
it. Produce a Markdown notes file: a mini guide that clearly explains
the concept at a glance. No new executable code.

## Reasoning

**Italiano:**

```text
INIZIO
  SELEZIONA il concetto chiave: Routing Express e risposte HTTP
  STRUTTURA il prompt per l'AI Tutor:
    "Spiega differenze tra res.send(), res.json(), res.type('html').send(),
     come usare req.query e quali status HTTP impostare."
  PRODUCI il file GUIDA.md contenente:
    - Definizione del framework Express
    - Tabella comparativa dei metodi di risposta
    - Esempi di utilizzo pratico e validazione query string
    - Glossario dei codici di stato HTTP (200, 400, 404, 500)
FINE
```

**English:**

```text
START
  SELECT core concept: Express routing and HTTP response formats
  STRUCTURE tutor prompt:
    "Explain differences between res.send(), res.json(), res.type('html').send(),
     how to use req.query, and which HTTP statuses to use."
  PRODUCE the GUIDA.md file containing:
    - Express framework overview
    - Response methods comparison table
    - Practical usage examples and query validation
    - Essential HTTP status codes glossary (200, 400, 404, 500)
END
```
