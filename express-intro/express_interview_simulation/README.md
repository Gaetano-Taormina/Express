# Exercise 7

**Italiano:**
Interrogazione guidata dalla AI. Fatti interrogare dalla AI. Scrivi un prompt
che trasformi la AI in un interrogatore su un concetto o codice già affrontato:
domande una alla volta, valutazione delle tue risposte, correzione e
prosecuzione finché non hai dimostrato di aver capito.

**English:**
AI-guided assessment. Get questioned by AI. Write a prompt transforming AI into
an examiner on previously learned concepts: one question at a time, evaluation
of answers, feedback/corrections, and progression until full understanding is
demonstrated.

## Reasoning

**Italiano:**

```text
INIZIO
  DEFINISCI il prompt esaminatore per l'AI:
    "Agisci come docente esaminatore. Poni domande una alla volta
     su Express (scaffolding, routing, res methods, query string),
     correggi e prosegui fino a comprensione dimostrata."
  SIMULA la sessione registrata in INTERROGAZIONE.md:
    - Domanda 1: Differenza tra res.send() e res.json()
    - Domanda 2: Gestione e validazione di req.query
    - Domanda 3: Watch mode nativo in Node.js (node --watch)
  VALUTA e valida ogni risposta con feedback chiaro
FINE
```

**English:**

```text
START
  DEFINE examiner prompt for AI:
    "Act as an examiner. Ask one question at a time about Express
     (scaffolding, routing, res methods, query strings, HTTP status),
     evaluate and continue until mastery is shown."
  SIMULATE assessment transcript recorded in INTERROGAZIONE.md:
    - Question 1: Difference between res.send() and res.json()
    - Question 2: req.query management and validation
    - Question 3: Node.js native watch mode (node --watch)
  EVALUATE each answer with actionable feedback
END
```
