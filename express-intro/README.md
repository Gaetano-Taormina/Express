# Express Intro & Practical Homeworks

**Italiano:**
Raccolta degli 8 progetti ed esercitazioni introduttive su **Express.js & Node.js**, comprendenti simulazioni di colloqui tecnici, guide concettuali sul ciclo Request/Response e API REST per cataloghi (giochi da tavolo, libreria, videogiochi, bacheca eventi e guide turistiche).

**English:**
Collection of 8 introductory projects and homeworks covering **Express.js & Node.js**, featuring technical interview assessments, architectural conceptual guides, and full RESTful catalog APIs (board games, bookstore, video games, event board, and city travel guides).

---

## Come eseguire i progetti / How to Run Locally

**Italiano:**

1. Entra nella cartella desiderata (es. `cd 01_express_intro`)
2. Installa le dipendenze: `pnpm install` (o `npm install`)
3. Avvia il server di sviluppo: `pnpm dev` (o `npm run dev`)
4. Avvia in produzione/standard: `pnpm start` (o `npm start`)

**English:**

1. Navigate to the desired directory (e.g., `cd 01_express_intro`)
2. Install dependencies: `pnpm install` (or `npm install`)
3. Start development server: `pnpm dev` (or `npm run dev`)
4. Start standard/production server: `pnpm start` (or `npm start`)
