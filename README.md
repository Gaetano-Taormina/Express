**Italiano:**
Raccolta completa degli esercizi e progetti su **Express.js & Node.js** sviluppati durante il percorso Boolean, strutturata in moduli tematici indipendenti. ## Come eseguire i progetti / How to Run Locally

1. Entra nella cartella di un esercizio (es. `cd express-routing-api/01-welcome-timestamp-server`)
2. Installa le dipendenze: `pnpm install` (o `npm install`)
3. Avvia il server in modalità watch: `pnpm dev` (o `npm run dev`)
4. Oppure avvia in modalità standard: `pnpm start` (o `npm start`)
